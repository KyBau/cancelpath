# CancelPath Privacy Policy
Effective 2026-10-13. CancelPath is a read-only MCP server that returns public cancellation instructions.
- **Data collection:** none beyond the merchant name in each request, which is processed in memory to answer it. No accounts, no cookies, no authentication, no personal data requested.
- **Usage and storage:** requests are not logged or stored by the application. The hosting provider may keep standard transient infrastructure logs (IP, timestamp) under its own policy.
- **Third-party sharing:** none. The server makes no outbound calls and sells or shares nothing.
- **Retention:** nothing is retained by the application.
